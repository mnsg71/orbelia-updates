# Установка Orbelia на новый компьютер

## 1. Скачать программу

Скачайте актуальный пакет:
[Orbelia 2.2.0](https://github.com/mnsg71/orbelia-updates/releases/download/v2.2.0/Orbelia_2_v2.2.0.zip).

## 2. Подготовить папку

1. Создайте на новом компьютере папку `orbelia_v2`.
2. Распакуйте ZIP внутрь неё.
3. Проверьте путь `orbelia_v2\Program\Orbelia_2.exe`.
4. С основного компьютера скопируйте рядом с папкой `Program` утверждённый
   файл `Сборочный бланк 2026 год.xlsm`.

GitHub-пакет не содержит рабочую базу, заявки, долги или Excel-шаблон.

## 3. Перенести рабочие данные при необходимости

Если на новом ПК нужны существующие заявки, отгрузки и долги, на основном
компьютере нажмите в Orbelia кнопку **«Создать переносимую папку»**. Перенесите
созданную папку флешкой и импортируйте её в Orbelia на новом ПК.

Если нужна чистая установка, просто запустите программу — локальная база
создастся автоматически.

## 4. Первый запуск

Запускайте только `Program\Orbelia_2.exe`.

На управляющем ПК откройте **«Администрирование → Устройства»**, нажмите
**«Создать файл подключения для нового ПК»** и задайте пароль. Перенесите файл
на новый компьютер, затем там нажмите **«Подключить этот ПК файлом»** и введите
пароль.

После подключения компьютер автоматически получит собственный идентификатор,
появится в списке управляющего ПК и будет получать актуальные карточки товаров
и паллетные правила при каждом запуске.

## Важно

- Не публикуйте и не отправляйте никому рабочую базу `Data\orbelia.db`.
- Не копируйте между компьютерами папку `Settings` вручную.
- Если два ПК показывают одинаковый ID, на втором нажмите
  **«Создать новый ID этого ПК»** — рабочая база при этом не изменится.
- Без интернета Orbelia продолжает работать с последними локальными правилами.
